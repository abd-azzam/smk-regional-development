# SMK vs SMA and regional development (Indonesia)

District-by-year panel. Research question: does the share of vocational (SMK) schools relate to regional development?

## Layout

| Part | Folder |
|---|---|
| Raw data | `data/DAPOER`, `data/DIKMEN`, `data/SMK`, `data/PDRB`, `data/crosswalk`, `data/Indeks Pembangunan Tenaga Kerja`, `data/Persentase Tenaga Kerja Formal` |
| Clean data | `data/PANEL` |
| Scripts | `Do File/` (Stata), top-level `*.py` (Python) |
| Output | `Result/` (regression logs, tables), `Images/`, `Maps/` |
| Git history | this repo |

## Excluded

- `data/AEJApp_2019_0309_Replication/`: third-party replication package, 1.1 GB.
- `Book/`, `Official's Document/`, `New Literature/`, `Paper/`: literature and manuscripts, not research inputs.
- `Data.rar`: archive, not in the layout above.
